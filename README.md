3  Passage Theory
The foundational dynamics theory — powerful when local, false when universalized.
CORE LAW  Configuration conditions Passage; engagement changes configuration; changed configuration changes later Passage.


Passage Theory is recursively general as a question about changing possibility, not a theory of everything. It supplies no empirical fact, causal truth, meaning, value, permission, authority, legitimacy, decision, or world effect by itself.
